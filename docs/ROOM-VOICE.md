# 純客戶端房間語音與音樂廣播（0.20.2）

沿用「一起聽 → 直連房間」；房主電腦轉送同房間音訊，跨網路可使用原有
「一鍵公網穿透」。不需要在 Minecraft 伺服器安裝插件，也不需要租用伺服器。
這是房主轉送，不是玩家間的 P2P 網狀連線；房主需保持在線。

## 使用

1. 完全退出遊戲，安裝與環境對應的 0.20.2 完整包或更新包。原版四版本共用
   vanilla 包，LeviLamina 26.60.7 使用獨立 LL 包。保留設定及現有 ModMenuBE。
   本包不包含 BSChat、Minecraft 伺服器插件或 ModMenuBE。
2. 一位玩家透過「一起聽 → 直連房間」開房。區域網路分享完整邀請；不同網路
   使用「一鍵公網穿透」分享公網邀請。其他玩家使用 0.20.2 加入同一個房間。
3. 點「房間語音」，或在 HUD 編輯／設定中心找「語音與音樂廣播」。
   先開「房間語音」才能收聽；要說話再單獨開「麥克風」。三個開關初始皆關閉，
   以後保留你明確選擇的設定。單純開頁不開麥、不連房、不下載或播放音樂。
4. 想分享本機正在播放的歌曲，再開「廣播當前音樂」。音樂取自播放器最終輸出，
   不擷取桌面或其他程式聲音。暫停或靜音本機播放器時停止音樂廣播，麥克風獨立。
   若同一首歌曲已透過一起聽同步播放，接收者可靜音本機播放器避免雙重聲音；
   「接收音量」獨立控制房間音訊。
5. Esc 返回上頁，切出遊戲再切回；有效房間的背景語音與播放應持續。
   離房、斷線或關閉房間語音會釋放收音／播放裝置並清掉舊資料。

在 ModMenuBE 普通設定綁定「切換麥克風」及「切換拒聽」，支援組合鍵，
預設無綁定；不需要打開播放器頁才能使用。拒聽會停止收聽與麥克風／音樂送出，
解除後恢復原來的開關與裝置。快捷鍵不會自行啟用整個房間語音。

語音頁另有「麥克風輸入裝置」及「耳機／喇叭輸出裝置」，選完即由背景工作套用。
插拔裝置後按「刷新音頻裝置」。指定裝置不存在會顯示錯誤，不自動換到其他麥克風。
只改房間音訊，不改本機音樂播放器裝置。裝置列表及切換本身不會開麥。

設定保存在 `config/muonium/room-voice.json`；不變更原有音源登入、歌單或快取。

## 距離音訊

預設仍為房間廣播。需要距離效果時，雙方進入**同一個 Minecraft 世界**，在語音頁
開啟「距離音訊」。麥克風與音樂都會從傳送者所在位置發聲；距離越遠越小聲，轉頭
有左右方向感，隔著已知方塊會變小、變悶。運鏡期間傳送位置沿用獨立玩家眼睛資料，
接收方依觀看鏡頭聽方向。可選8／16／32／64格，預設32格；超出範圍停止接收聲音。

此版本沒有跨電腦共用的伺服器／世界ID，**不會自動核對雙方是否同服同世界**。
請只把同一世界的玩家放在同一距離語音房間。改變／失去本機世界後，距離音訊暫停；
回到正確世界再點「重新啟用當前世界」。重開遊戲後亦需明確重新啟用；開頁不會代按。
跨維度或位置過期時無聲。距離模式需要新版本房主及雙方客戶端；舊版成員不會收到
被降級成全音量的距離音訊，普通房間音訊仍可相容。

遮擋沿用附近33格方塊快照與碰撞形狀，在語音背景執行緒計算。未知區域採保守悶音，
不視為已確認空氣；不是完整遠距離聲場或HRTF。音量與濾波會漸變，避免位置更新爆音。
選擇距離模式代表同意向同房間支援者傳送當前座標；座標不寫入設定、日誌或歷史。

「一起聽」同步歌曲、進度，成員各自取流；「廣播」傳送已播放出的音訊。接收者不必
取得同一音源。距離模式下可把廣播當成附近可聽到的音樂；避免接收端重複播放同一首。

## 本輪人工驗收

以下保留原先的驗收清單。玩家已確認普通房間語音與0.20.1距離語音可用；新增增益通過離線驗證；額外實體麥克風測試依維護者決定跳過，跨國／弱網情境未獲確認。

- 兩端初次開頁皆關閉，不提示收音；只開房間語音時不開麥。
- 同房間雙向說話；任一端關麥後立即停止傳送，其他端仍能說話。
- 一端播歌並開音樂廣播，另一端聽到；暫停、靜音、切歌及關閉廣播正常。
- 綁定兩個語音快捷鍵，關閉播放器頁測試切換、長按不重複及切出返回；拒聽時兩端應收不到該端送出的音訊，解除後恢復。選擇麥克風／耳機、刷新列表，確認保留設定。
- 頁面 Esc 返回、切換視窗／登入頁後可操作，背景語音不中斷。
- 離房、踢出、重連與換房，不播放舊房間音訊；重新開關麥克風仍能說話。
- 雙方同世界開距離音訊，左右移動、轉頭、走遠及超過範圍；比較空氣、石牆與門洞。
  切維度、退出世界、重進與重開遊戲後需重新確認；拒聽期間不得送音或收聽。
- 原版及 LL 各試一次；跨網路一鍵穿透另外測試。與舊版成員混用仍可一起聽，
  0.19成員可用普通房間語音但無距離音訊，更早版本不支援本路線語音。
  距離音訊需由0.20客戶端開設的直連／公網房間。

## 限制

最多八個連線參與語音，含房主；超出仍保留一般房間功能。使用48kHz／20ms
單聲道Opus，目標32kbps，接收輸出為48kHz立體聲。房主轉送給其他成員，流量隨人數增加。
穿透服務、代理與網路抖動會影響延遲；TCP 擁塞仍可能讓語音短暫中斷。
佇列有上限，延遲太久的音訊直接捨棄，不保證弱網順暢。

可選麥克風及耳機／喇叭裝置，預設跟隨系統，建議耳機；沒有回聲消除、降噪、錄音、語音辨識、
Minecraft 玩家自動尋房。房間身份沿用既有本機身份與邀請驗證，
不代表 Xbox 帳號驗證。公網穿透沿用 WSS；一般 LAN 直連使用原有 TCP。

兩端都要升級；不會改寫遊戲封包、遊戲 EXE、hook 地址或 ModMenuBE。
0.17.1、獨立 0.18.0 BSChat 、0.19.0與0.20.0測試套件保留，0.20.2公開發布，不會自動安裝。

## 距離語音驗收參考（0.20.1已由玩家確認）

兩端及房主更新後，在同一世界、同一房間開啟語音及距離模式；若原本已開距離模式，
按「重新啟用目前世界」。先相隔2格確認雙向說話，再走出範圍、走回、左右轉頭，
最後開關播放器與暫停頁確認不中斷。退出世界／切維度應暫停；回到相同世界後需重新確認。
普通及距離語音已由玩家確認可用；此處保留複查步驟。

## 麥克風增益（0.20.2）

入口：一起聽 → 直連房間 → 房間語音 → 麥克風增益；HUD編輯的「語音與音樂廣播」也能調整。
提供0～400%（每50%一檔），預設100%。麥克風放得較遠可先試200%，再請同伴確認音量。
調整立即生效並保存，不會重連或自動開麥。只放大麥克風，音樂廣播維持原音量；
「發送音量」仍是兩者混音後的總音量。增益也會提高底噪，超過滿刻度的訊號以整幀峰值限制處理。

若日後需要實體麥克風複查，可在同一房間比較100%／200%／400%及0%，確認聲音大小、音樂廣播不受影響，
關頁／重開後設定保留。普通和距離模式都適用；0.20.1距離功能已獲玩家確認可用。
