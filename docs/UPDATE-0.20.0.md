# 0.20.0 距離語音與音樂廣播測試版

- 語音頁新增可選距離音訊、8／16／32／64格範圍與重新啟用目前世界。
- 麥克風與音樂廣播皆有遠近衰減、左右立體聲及方塊遮擋悶音，平滑調整音量／濾波。
- 沿用目前已驗證的世界、方塊及獨立運鏡玩家資料；新增DSP與射線只在語音背景執行緒。
- 世界／維度改變、位置失效、拒聽與斷線會停止距離音訊；切世界後需明確重新啟用。
- 新增距離能力協商，舊客戶端不會把距離音訊誤當全房間聲音。普通房間音訊保留。
- 預設距離模式關閉，保留麥克風、耳機、拒聽、快捷鍵及音量設定。開頁保持被動。

同一距離房間的玩家須位於同一遊戲世界；本版本無法自動核對伺服器／世界身份。
近處方塊快照外的路徑保守悶音；未提供HRTF、完整遠距聲場或回聲消除。
兩端及房主需升級。未修改遊戲hook、原生佈局、ModMenuBE、編解碼器或已安裝遊戲。
舊套件保留；離線結果見VERIFICATION.json，實體麥克風與兩台電腦遊戲驗收仍待測試。
