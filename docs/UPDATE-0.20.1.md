# 0.20.1 距離語音修正候選

修正打開播放器／暫停介面後，距離語音無法啟用或反覆暫停的問題。
0.20.0把HUD鏡頭的可用狀態當作世界身份，介面切換會讓確認失效。

- 語音改用既有精確版本合約驗證的本地玩家位置／朝向，透過獨立唯讀私有傳輸取得；不依賴運鏡是否開啟。
- 開關介面不改變語音的世界身份；真正離開世界、維度／玩家身份改變、位置超時仍停止距離音訊，並要求重新確認。
- 方塊資料在介面中仍可按既有預算更新；未知路徑維持保守悶音。
- 增加有界的語音診斷，記錄資料是否有效、協商及收發計數；不記錄座標、帳號、房間憑證或聲音。

未新增遊戲掛鉤、RVA或佈局，未改寫EXE、ModMenuBE、編解碼器及已安裝遊戲。
普通房間語音與設定格式保留。兩端及房主請使用本候選；進入相同世界後開啟／重新確認距離模式。
舊套件保留，未自動安裝或發布。離線與兩台電腦遊戲驗收分開；實體測試仍待完成。
