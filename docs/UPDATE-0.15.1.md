# 0.15.1：音源錯誤處理修補候選版

基於 0.15.0 與上游 2.6.0（`eb541684`），保持 Java 21。

- QQ：讀取並保留 HTTP、回應頂層及 `req_0.code` 的失敗；不再讓外層 104009 被內層的 result=0 蓋掉。保留成功 purl 與既有音質選擇。診斷不輸出憑證前綴。
- Spotify：搜尋尚未登入／授權失效時顯示前往帳號頁登入的提示；區分權限拒絕、限流及網路失敗。保留官方登入要求，不提供匿名或本家完整音訊下載。
- Bilibili：播放接口的 HTTP 拒絕碼帶入最終失敗提示，避免通稱沒有版權。每首分 P 的失敗資料獨立，短期保留於記憶體。
- 酷狗：`pkg`／`buy`／`vip` 或權限探測拒絕，提示檢查當前帳號的歌曲／音質授權；成功取流後清除此提示。未移除權益檢查。
- 所有 HTTP 串流：選定音訊及其已有備援均遭拒絕時，不再重複改用整首下載請求同一地址。保留格式／容器不支援時的既有整首下載回退，以及正常備援和邊下邊播。

本輪 DLL 只有版本與精確設定描述雜湊更新，原生掛鉤、版本映像驗證、相機共存及 D3D11／D3D12 程式碼未改。普通四版本共用套件，LeviLamina 26.60.7 套件獨立；不含 ModMenuBE，不更動帳號、設定或歌單。預抓下一曲及永久媒體快取仍預設關閉。

## 日誌能證實的範圍

附件的有效播放會話為 0.14.7／0.14.8 LeviLamina，以及 0.13.0 普通載入版，沒有 0.15.0。Spotify 明確為 `NOT_LOGGED_IN`；酷狗有 `pkg` 與會員音質拒絕；Bilibili 多次 API HTTP 412，另有 CDN HTTP 567。QQ 失敗前沒有足夠取鏈日誌，其封面 404 不代表音訊 404。

受控匿名公開接口對照中，兩個 Bilibili 範例可取得音訊表示；QQ 則可重現 `req_0.code=104009` 而各項 result=0、purl 為空。這證明錯誤碼處理缺口，不代表已判定玩家 QQ 帳號被拒的根本原因。

**本版修正錯誤處理與重複下載，不宣稱繞過 412／567、帳號權限或已讓所有音源可播。** 尚需玩家以此版測試原失敗歌曲，核對新的同次 JVM／原生日誌。離線測試與封裝核驗不代替遊戲內驗收。

完整證據與限制見 [日誌分析](SOURCE-FAILURES-20261122.md)。
