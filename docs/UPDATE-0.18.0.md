# 0.18.0 — 可選語音與音樂廣播測試版

新增獨立 BSChat 整合，適用 Windows x64、1.26.60.05、LeviLamina 26.60.7。
完整包／更新包包含客戶端插件，服務端需另裝本輪 BSChat 服務端測試包。
兩位玩家與伺服器皆需支援 BSChat，普通伺服器保留本機播放。

- HUD 編輯／設定中心新增「語音與音樂廣播」：廣播開關、發送音量、連線狀態、
  明確開啟 BSChat 語音設定的按鈕。單純開頁不啟動操作。
- 廣播預設關閉，麥克風預設關閉，快捷鍵預設無綁定。保留已存在的明確設定。
- 從音樂引擎最終輸出取得 PCM，不錄製其他程式聲音；未開麥克風也能廣播。
- 暫停、靜音、離服及過期音訊停止廣播，重連清除舊音訊。
  語音與音樂共用 BSChat 原有的伺服器傳輸、距離和權限規則。
- 已實作有界佇列、非等待 IPC、實際 Opus 編解碼及服務端混音測試；
  人工雙人遊戲、實際麥克風、HUD 圖示及伺服器部署仍待驗收。

本輪不修改遊戲 hook／相機／渲染地址、ModMenuBE 或已安裝遊戲。
Muonium 原生 DLL 僅更新版本與設定描述雜湊名單。
0.17.1 已驗收檔案保留，未安裝、未上傳 GitHub。
YouTube 既有問題不在本輪修復範圍，不能視為已解決。

部署、限制、授權與測試步驟見 integrations/bschat/README.md；
離線結果與套件雜湊以隨包 VERIFICATION.json、SHA256SUMS.txt 為準。
