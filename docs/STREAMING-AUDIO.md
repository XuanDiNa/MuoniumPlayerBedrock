# 0.14.7 線上音源邊下邊播

播放入口依實際音訊內容選解碼器，不再限制為網易雲 MP3／FLAC，也不信任副檔名。
解出約一秒 PCM 後交給原有播放器；網路與解碼在背景執行，音訊回呼只讀本機 PCM。
一般播放最多向前解碼約十二秒；使用者開啟下一首預下載或完整混音分析時才繼續讀完整首。

| 音源／路徑 | 本版處理 |
| --- | --- |
| 網易雲、QQ、GD、酷狗，及 LX 提供的酷我／咪咕等 HTTP 音源 | 共用漸進解碼入口；MP3、FLAC、AAC／ADTS、M4A／MP4、OGG Vorbis、WAV PCM／float |
| Bilibili | 沿用原作 CDN User-Agent／Referer／Origin；AAC 純音訊、普通 MP4 及 DASH 分片 MP4；不下載影片 |
| 汽水 | 明文音訊使用共用入口；現有 play_auth 授權支援的整幀 AES-CTR／8-byte IV 音訊逐幀解密；不新增授權或繞過權限 |
| YouTube | 0.15.4 保留成功的分段大小、短等待與 Retry-After，403 可嘗試網址 range 備援；沿用有效 CDN URL，必要時更新同格式連結，驗證 Range／長度／強 ETag，斷線從未交付位元組重試；保留代理。首段上限 256 KiB、之後最多 1 MiB，首段仍需接收完畢 |
| Apple HTTP 試聽／既有換源結果 | 可解碼 HTTP 音訊使用共用入口；Apple 原生完整版仍由原有本機引擎取得 |
| Spotify | 原作是歌曲資料來源，由原有換源機制找可播音源；不宣稱新增 Spotify 官方串流 |
| 本地檔案、廣播／HLS | 保留本地直讀與既有電台串流，不改成下載檔案 |

普通 MP4 的索引在檔尾時，使用可驗證同一物件的 HTTP Range 讀取索引。
DASH 即使使用一個很大的 mdat，也按樣本讀取，不把整個 mdat 下載到記憶體後才播。
MP3／FLAC 保留既有跳轉；普通 MP4 與 WAV 可用 Range 跳轉。ADTS、OGG 和分片 MP4
的首次遠距跳轉使用順序緩衝，沒有將它們誤當 MP3 建索引。

以下情況保留原有完整檔案／解碼回退：伺服器不允許讀取檔尾索引、沒有可用時長資訊的
裸 AAC／OGG／分片來源、未支援的加密布局或格式。已交付的串流若中途損壞，維持既有
失敗／手動重試處理，不能當作正常曲終而自動跳過歌曲。

「預下載下一首」與「保留音樂快取」仍預設關閉。播放中的 PCM 工作檔仍會暫時使用磁碟，
結束／取消後清理；這不等於零磁碟寫入。開啟保留快取時才保留完成的可重播音訊。

離線驗證使用本專案產生的正弦音訊和本機 HTTP：刻意扣住檔尾，驗證實際 AudioPlayer
準備成功且能讀到非靜音 PCM。另測試授權加密樣本、索引在檔尾、單一大型 mdat、取消、
跳轉、無 Range、錯誤格式與畸形索引。不使用玩家帳號或真實平台登入資料。
這些結果不代替各平台的實機起播速度、網路穩定性或 Minecraft FPS 驗收。
