# 0.19.0 — 純客戶端房間語音測試版

- 不需要 Minecraft 伺服器插件：房主沿用一起聽直連／一鍵穿透轉送語音。
  原版 1.26.45.01／1.26.51.01／1.26.52.03／1.26.60.05 共用一包，LL 26.60.7 獨立。
- HUD 編輯／設定中心新增房間語音、麥克風、音樂廣播、發送／接收音量與狀態。
  一起聽直連頁提供「房間語音」按鈕，Esc 返回原頁，失焦不停止有效房間音訊。
- 新增可綁定組合鍵的「切換麥克風／拒聽」，預設無綁定；拒聽暫停收聽和所有送音，解除恢復原設定。可選麥克風及耳機／喇叭裝置，背景列出與切換。
- 三個開關預設關閉；只有明確開麥且加入支援的房間才收音。不擷取系統音訊。
  廣播使用音樂引擎最終輸出；暫停、靜音、離房及斷線清理舊音訊。
- 獨立 Opus 1.5.2 編解碼器；房主只轉送同房間已協商的連線，限制八人、速率、
  封包大小與資料新鮮度。語音使用有界佇列，控制封包優先，阻塞連線會被關閉。
  舊客戶端仍可一起聽，不能收發語音。

本輪不修改遊戲 hook／相機／渲染地址、ModMenuBE 或已安裝遊戲。
Muonium 原生 DLL 新增兩個快捷鍵設定／私有事件及版本描述；新增的編碼 DLL 不依賴遊戲。
不包含 BSChat。已驗收 0.17.1 和獨立 0.18.0 候選保留。

離線真實編解碼、房間引擎、TCP／WebSocket 通道及注入音訊裝置測試，與實際
麥克風及雙人遊戲驗收分開。後者仍待測試，結果以隨包 VERIFICATION.json 為準。
[使用及驗收步驟](ROOM-VOICE.md)。未自動安裝，未上傳 GitHub。
