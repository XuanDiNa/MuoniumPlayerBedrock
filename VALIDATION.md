# Verification boundaries

Users reported that the four game versions and the separate 26.60 LeviLamina variant run with their pre-publication baselines. This is basic runtime feedback, not acceptance of every feature/scenario.

Public packages replace four text fonts with OFL Noto assets and add license/provenance records. The prior public edition checked font parsing, multilingual glyph coverage, real Skija rendering, UI input, alpha coverage and native D3D12 fixtures offline. These checks did not launch Minecraft and are historical evidence, not a fresh campaign for every release.

Republished public2 uses a replacement native 0.12.0-test3 DLL. The prior DLL refused reviewed 26.60 console/rebuild-order images before creating the Workspace provider. Four complete image identities are added; all original identities, entry guards, addresses, native contracts and loader separation remain unchanged. Fresh targeted admission and real Workspace API tests are recorded in docs/PUBLIC-VERIFICATION.json. The new DLL awaits manual acceptance on all supported game versions. The Java engines and separate accepted LeviLamina DLL are unchanged. Historical artifacts remain local.

Known limits include incomplete entity lyric occlusion and third-party tunnel/service stability. No FPS gain or perfect cross-machine support is claimed. Public package identities and test counts are recorded in docs/PUBLIC-VERIFICATION.json and per-package PUBLIC-EDITION.json.
